# Security Boundaries

AI Network Mapper is a defensive analytics platform.

## Allowed Contributions

- Asset discovery ingestion.
- Scan normalization.
- Inventory, graph, risk, and timeline analysis.
- Vulnerability metadata enrichment.
- MITRE ATT&CK mapping.
- Defensive recommendations.
- Safe evidence-grounded explanations.

## Disallowed Contributions

- Exploit generation.
- Payload generation.
- Automated exploitation.
- Credential theft or credential harvesting.
- Credential spraying or brute force automation.
- Offensive command generation.
- Post-exploitation workflows.
- Evasion or stealth functionality.

Contributions crossing these boundaries should be rejected even if they are technically interesting.
