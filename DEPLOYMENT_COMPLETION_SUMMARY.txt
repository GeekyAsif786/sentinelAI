DEPLOYMENT ROLLBACK PROCEDURES
================================================================================

If critical issues are detected:

Database Rollback (15-20 minutes):
  1. Restore from backup: psql < backup.sql
  2. Restart services: systemctl restart ...
  3. Verify: SELECT COUNT(*) FROM scan_runs

Code Rollback (10-15 minutes):
  1. Revert: git revert HEAD --no-edit
  2. Reinstall: pip install -r requirements.txt --no-deps
  3. Restart: systemctl restart sentinelai-api sentinelai-worker
  4. Verify: curl http://localhost:8000/health
