# Contributing

Contributions must preserve the defensive scope of the project.

Before submitting code:

- Keep scanner execution behind policy validation.
- Avoid offensive automation.
- Add or update tests for parsing, scoring, graph traversal, API behavior, or UI state changes.
- Keep AI optional and evidence-grounded.
- Do not commit secrets.
- Prefer typed, explicit code over clever shortcuts.

Code that introduces exploit generation, payload generation, credential abuse, or automated attack execution is out of scope.
